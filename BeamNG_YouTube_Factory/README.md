# BeamNG YouTube Factory

Автономная AI-студия: вы пишете сценарий обычным языком → программа сама снимает его в **BeamNG.drive**
(водитель, оператор, запись через OBS), монтирует **Shorts 9:16 / 16:9** с музыкой и эффектами и готовит
заголовок, описание и хештеги для YouTube.

> Пример: «Красный Lamborghini едет по горной дороге, разгоняется, перепрыгивает через автобус,
> теряет управление и врезается в стену».

---------------------------------------------------------------------------------------------------

## ⚠ Что проверено, а что нет (читайте первым)

Проект разрабатывался в облачной Linux-среде, где **нет ни BeamNG.drive, ни OBS, ни Windows**. Поэтому:

| Часть | Статус |
|---|---|
| AI Director (разбор сценария, проверка и замена ресурсов, ИИ-провайдеры) | ✅ тесты |
| AI Driver (регуляторы, калибровка руля, прыжок/занос/таран, детектор событий) | ✅ проверено на кинематическом симуляторе, **не на реальной игре** |
| Монтаж (OpenCV + FFmpeg: анализ, слоу-мо, кадрирование 9:16, музыка, SFX) | ✅ реально выполняется в тестах, на тестовых роликах |
| Пайплайн (чекпоинты, повтор сцены, остановка, продолжение, SQLite) | ✅ сквозной тест (игра и OBS подменены) |
| GUI (PySide6) | ✅ запускается, проверен в offscreen-режиме |
| Вызовы `beamngpy` | ✅ сверены с реальным пакетом beamngpy 1.36 (сигнатуры, тест на настоящих классах `Scenario`/`Vehicle`/`ProceduralCube`) |
| **Работа с настоящей BeamNG.drive** (спавн, рампа/стена, ИИ-вождение, камеры) | ⚠ **не проверена в игре** — ваш первый запуск и есть первая проверка |
| **Работа с настоящим OBS** | ⚠ код написан по API obsws-python 1.8, проверен на имитации ответов |
| Загрузка на YouTube | ⚠ код по официальному API, не запускался (нужны ваши ключи) |

Известные места, где в игре возможна подстройка: ориентация машины при спавне (программа сама измеряет и
выравнивает), знак руля (калибруется автоматически), координаты старта карт `gridmap_v2` (помечены «не проверено» —
запишите свою точку, см. ниже), поддержка свободной камеры в вашей версии игры (если недоступна — работает штатная камера,
причина в журнале).

### Про BeamNG.drive и BeamNG.tech
`beamngpy` официально создавался для **BeamNG.tech**; обычная **BeamNG.drive** поддерживает его подмножество.
Программа использует только базовые вызовы: загрузка сценария, спавн машин и простых объектов, `Vehicle.control`, встроенный
ИИ (`vehicle.ai`), сенсор состояния (`State`), камеры (`bng.camera`). **Не используются** камерные сенсоры, лидар, радары и
прочее, что доступно только в Tech. Если в вашей версии игры какой-то вызов недоступен, программа пишет об этом в журнал
и продолжает (камера) либо останавливает сцену с понятным сообщением (спавн/управление).
Если `beamngpy` не может подключиться к вашей BeamNG.drive — это ограничение версии игры; тогда доступен режим
**«Смонтировать мой видеофайл»** (запись ведёте сами, монтаж — автоматически).

## Установка (Windows 10/11)

1. Установите **Python 3.11+** (https://www.python.org, галочка *Add python.exe to PATH*).
2. Установите **BeamNG.drive** и **OBS Studio** (https://obsproject.com).
3. Распакуйте проект, запустите **`install.bat`** — создаст `.venv`, поставит зависимости, попробует установить FFmpeg через winget
   и выполнит проверку системы.
4. Запустите **`start.bat`**.

### Настройка OBS (один раз)
1. OBS → *Инструменты → Настройки WebSocket-сервера* → включить, задать пароль (порт 4455).
2. Создайте сцену с источником **«Захват игры»** (Game Capture) или «Захват окна» для BeamNG.drive и источником звука
   (**«Захват звука приложения»** / «Захват вывода звука»). Запись — 1080p, 60 FPS, кодировщик NVENC/x264.
3. В программе: *Настройки → OBS* — пароль (и, если нужно, имя сцены). Отметка «Менять разрешение/FPS OBS» позволит программе
   выставлять разрешение по выбранному качеству.
Если OBS недоступен, программа пробует запасной захват окна средствами FFmpeg (gdigrab; игра должна быть в оконном/безрамочном режиме,
звук только при указанном устройстве DirectShow).

### Настройка игры
*Настройки → BeamNG.drive → Папка игры* (где лежит `BeamNG.drive.exe`, например
`C:\Program Files (x86)\Steam\steamapps\common\BeamNG.drive`). По папке `content/vehicles` и `content/levels` программа проверяет,
какие машины и карты реально установлены, и автоматически подставляет замену.

### Калибровка карты (рекомендуется)
Для трюков нужна ровная площадка (≥ 400 м), для езды по дороге — точка на дороге. Координаты в `config/maps.json` помечены
«не проверено». Запишите свои:
```
.venv\Scripts\python.exe tools\record_spawn.py gridmap_v2
```
Загрузите карту в игре (Свободная езда), поставьте машину в нужное место и направление, нажмите Enter → точка сохранится в
`config/user_maps.json` и будет использоваться автоматически. Так же добавляется любая новая карта.

## Как пользоваться

1. Вкладка **«Создать видео»** → напишите сценарий (или «Вставить пример»).
2. **«Предпросмотр плана»** показывает, как режиссёр понял сценарий, какие замены сделал и какие есть предупреждения.
3. Выберите машину/карту (или «Автоматически»), длительность, качество, камеру, форматы.
4. **▶ GENERATE VIDEO**. Прогресс и журнал — справа. **■ СТОП** безопасно останавливает процесс: запись завершается и сохраняется.
5. Готовые файлы: `output/projects/<проект>/final/` — `*_shorts_9x16.mp4`, `*_16x9.mp4`, `youtube_metadata.json`.
   Сырые записи — `output/projects/<проект>/raw/` (никогда не удаляются).

**История**: просмотр, «Продолжить» (после сбоя снимает только недостающие сцены), «Переснять сцену», «Пересобрать монтаж»
(без игры), загрузка на YouTube, «Смонтировать мой видеофайл…».

Командная строка:
```
python main.py --check                       проверка системы
python main.py --plan "текст сценария"       план без игры
python main.py --cli --script-file examples\scenario_lamborghini.txt --duration 30
python main.py --edit C:\video\запись.mp4 --duration 30
```

### Как писать сценарий
Пишите глаголами действий. Несколько сцен — разделяйте пустой строкой или словом «Сцена».

| Что написать | Что сделает программа |
|---|---|
| «едет по горной дороге/трассе/шоссе» | встроенный ИИ игры ведёт машину по дорожной сети карты (`vehicle.ai`, режим `span`) |
| «разгоняется (до 150 км/ч)» | полный газ до скорости, удержание курса |
| «перепрыгивает через автобус», «прыгает с трамплина» | ставит рампу (наклонный куб) и автобус, подъезжает по оси рампы на нужной скорости |
| «теряет управление», «занос», «дрифт» | резкий руль + ручник, затем «ловит» машину |
| «врезается в стену/автобус» | едет в цель на заданной скорости, после удара катится 3 с |
| «тормозит», «поворачивает налево/направо» | торможение / поворот на 90° |
| «красный/синий/…» | цвет кузова; «Lamborghini/Ferrari/…» → ближайший аналог (Civetta Scintilla) с пояснением |

**Важное техническое решение:** рампы и стены ставятся относительно точки старта и считают землю плоской. Поэтому езда по
горной дороге и трюки автоматически разделяются на **две сцены**: дорога на карте с дорожной сетью, трюк на ровной карте
(`gridmap_v2`). Это видно в плане и в предупреждениях; монтаж склеивает сцены в одно видео.

Для сложных/свободных формулировок подключите языковую модель (*Настройки → ИИ*): она строит план по тому же JSON-формату, а ответ
проходит проверку (неизвестные машины/карты/действия заменяются или удаляются с предупреждением). Без модели работает встроенный
разбор по правилам.

## Архитектура

```
main.py                 вход: GUI / CLI
core/                   модели, настройки, логи, проверка зависимостей, pipeline (оркестратор), токен остановки
ai_director/            сценарий → план: catalog, offline_parser, providers (Anthropic / OpenAI-совместимый / offline), director
ai_driver/              управление: controllers (скорость, курс, Стэнли), events (прыжок/авария/занос), driver, runtime_base
environment/            GameContent (что установлено), старт карты, beamng_session (ЕДИНСТВЕННОЕ место с beamngpy)
cameraman/              план ракурсов + управление камерой игры (свободная камера, режимы игры, смена ракурса по событиям)
recorder/               OBS WebSocket, запасной FFmpeg-захват, проверка качества записи
editor/                 анализ (OpenCV), планировщик, рендер (кадрирование/слоу-мо/звук), editor
youtube/                метаданные (ИИ/шаблон) и загрузчик (YouTube Data API v3, OAuth)
database/               SQLite: проекты, дубли, видео, журнал
gui/                    PySide6, тёмная тема
config/                 default_config.json, cars.json, maps.json (+ user_config.json, user_maps.json — ваши)
tests/  tools/  examples/  assets/(music, sfx)  output/  logs/
```
Игра отделена интерфейсом `SceneRuntime`: драйвер и оператор ничего не знают о beamngpy, поэтому управление проверяется
на симуляторе в тестах.

Как делается монтаж: события драйвера (прыжок, приземление, авария, занос) привязываются ко времени записи → вокруг них
вырезаются окна, ключевые моменты (авария/прыжок) идут в **слоу-мо с интерполяцией кадров**, пустые начало/конец отбрасываются
по анализу движения (OpenCV), всё подгоняется под заданную длительность (Shorts ≤ 60 с). Умное кадрирование 9:16: если камера
едет за машиной — машина по центру; если камера статична — следуем за центром локального движения (с ограничением скорости
панорамы). Звук: игровой + музыка (ваши треки из `assets/music`, иначе локально синтезируется простой трек) с «приглушением»
под игровой звук + эффекты на событиях (`assets/sfx/crash*.wav`, `jump*`, `landing*`, `loss_of_control*`; иначе синтез FFmpeg).
Переходы — быстрые «через чёрный», на ударе — короткий «punch-in» зум.

### Повторы и надёжность
* Сцена снимается до `production.max_scene_attempts` раз, пока не получены обязательные события (прыжок, авария).
* Каждый дубль и состояние проекта сохраняются сразу (`project.json` + SQLite). Запись при сбое/остановке корректно закрывается.
* Опасных системных операций нет: программа пишет только в `output/`, `logs/`, `config/user_*.json`. OBS-файл копируется, оригинал остаётся.
* Журнал: `logs/factory.log` + окно журнала + таблица `log` в БД.

## YouTube
1. Google Cloud Console → проект → включить **YouTube Data API v3** → OAuth-клиент «Приложение для ПК» → скачать JSON как
   `config/client_secret.json`.
2. «Загрузить на YouTube» (или галочка при генерации) → откроется браузер для входа. Токен сохранится в `config/youtube_token.json`.
3. По умолчанию видео загружается **приватным**. Ограничения YouTube: квота API (~6 загрузок/сутки по умолчанию), непроверенные
   API-проекты могут публиковать только приватные ролики.

## Тесты
`run_tests.bat` или `python -m pytest tests -v` (≈1–2 мин; нужен ffmpeg в PATH). Покрыто: Director, водитель на симуляторе,
детектор событий, геометрия, планировщик, реальный монтаж видео, пайплайн, БД, настройки, OBS (имитация), камера, адаптер beamngpy.

## Если что-то не работает
| Симптом | Что делать |
|---|---|
| `Проверка системы` → FFmpeg не найден | `winget install Gyan.FFmpeg`, перезапустить; либо путь в Настройках |
| Не подключается к BeamNG | проверьте папку игры; закройте уже запущенную игру; порт 25252 свободен; версия `beamngpy` должна соответствовать версии игры (`pip install -U beamngpy`) |
| Машина встаёт не туда / боком | `tools/record_spawn.py <карта>`; в логе будет «курс отличается на N° — выравниваю» |
| В кадре не видна игра | в OBS источник Game Capture должен показывать игру; запустите игру до записи |
| Нет ракурсов камеры | в журнале «свободная камера недоступна» — снимается штатной камерой игры |
| Прыжок не получился | увеличьте скорость в сценарии («на 120 км/ч»), «Дублей на сцену» ≥ 2; программа повторит сцену сама |
