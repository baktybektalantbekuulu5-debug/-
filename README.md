# NEW WORLD

Многопользовательская 3D-игра для ПК и мобильных устройств:
выживание, строительство, торговля, исследование открытого мира.

## Технологии
- Unity 6 LTS (версия 6000.0.x)
- Universal Render Pipeline (URP)
- Input System

## Как открыть проект
1. Установите **Unity Hub**: https://unity.com/download
2. В Unity Hub установите редактор **Unity 6 LTS**. Для телефонов добавьте модуль *Android Build Support*.
3. Скачайте этот репозиторий (`git clone` или кнопка *Code > Download ZIP*).
4. В Unity Hub: *Add > Add project from disk*, выберите папку проекта.
5. Если Hub скажет, что версия редактора не найдена, выберите установленную Unity 6.
   Согласитесь на обновление проекта.
6. Первое открытие занимает несколько минут: Unity скачивает пакеты и создаёт служебные файлы.

После первого открытия появятся новые файлы `.meta`. Их нужно сохранять в репозитории (коммитить).
