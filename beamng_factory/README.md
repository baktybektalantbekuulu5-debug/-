# BEAMNG YOUTUBE FACTORY

Автоматическая студия видео для BeamNG.drive. Сейчас готовы: этап 0 (проверка ПК) и начало этапов 1–2 (ядро, разбор сценария).

## Шаг 1. Проверка ПК (делается один раз, всё автоматически)

1. Скачайте папку проекта (ZIP ветки `claude/beamng-youtube-factory-mvshnw`) и распакуйте, например, в `C:\BeamNGFactory`.
2. Закройте BeamNG.drive, если она открыта.
3. Дважды щёлкните `beamng_factory\CHECK_PC.bat`.

Программа сама:
- установит Python 3.12 (если его нет) и нужные библиотеки;
- найдёт игру (Steam или папка), видеокарту, место на дисках;
- скачает FFmpeg и проверит, какой кодек записи работает на вашей видеокарте;
- запустит BeamNG.drive через официальный API BeamNGpy, загрузит карту West Coast USA, поставит красный ETK 800;
- проверит: AI-вождение, камеру, столкновение с пикапом и датчик повреждений, замедление времени, смену времени суток;
- запишет тестовое видео `projects\_doctor\test_capture.mp4`;
- сохранит найденные настройки в `config\settings.toml`.

Во время теста игры (около 1–2 минут после её загрузки) не трогайте мышь и не сворачивайте окно игры.

В конце откроется `projects\_doctor\report.txt` — скопируйте его текст и отправьте в чат.

## Структура

```
src/bfactory/
  core/       настройки, пути, логи
  system/     поиск игры, сведения о ПК, FFmpeg, окна Windows
  capture/    запись экрана FFmpeg
  director/   разбор сценария в план сцен
  doctor.py   проверка ПК
tests/        тесты (работают без игры)
```

Тесты: `python -m pytest`.
