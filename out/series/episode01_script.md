# «Тимур и Портал». Серия 1: «Планета скорпионов»

Длина около 3 минут. Стиль: 2D-перекладка как в «Бобе». Теги эмоций в квадратных скобках для Eleven v3.

| Голос | Stability | Style | Скорость |
|---|---|---|---|
| Рассказчик серий | 50% | 20% | 1.0 |
| Тимур | 35% | 45% | 1.0 |
| Профессор Зара | 50% | 30% | 1.0 |
| НОВА | 80% | 0% | 1.0 |

---

## СЦЕНА 1. Заставка (0:00–0:10)
Кадр: синяя карточка-чертёж, планета в оранжевых полосах, надписи «ЗНАКОМЬТЕСЬ, ТИМУР» и «ПЛАНЕТА СКОРПИОНОВ».

**РАССКАЗЧИК**
```
[calm] Знакомьтесь, это Тимур. [slightly ironic] Пятнадцать лет, боится темноты, пауков и контрольных по физике. [pause] Сейчас он узнает, что контрольная по физике была не самым страшным.
```

## СЦЕНА 2. Лаборатория (0:10–0:35)
Кадр: лаборатория Зары, гудит портал. Тимур осторожно трогает панель, НОВА летает рядом.

**ЗАРА**
```
[calm] Тимур, ничего не трогай. Портал ещё не откалиброван. [sighs] Это значит: ничего. Не. Трогай.
```

**ТИМУР**
```
[nervous] Я и не трогаю! Я просто… смотрю пальцем.
```

**НОВА**
```
[neutral] Зафиксировано касание панели управления. Портал активирован.
```

**ТИМУР**
```
[panicked] Что значит активирован?! НОВА, выключи его! Выключи! А-а-а!
```

## СЦЕНА 3. Падение (0:35–0:45)
Кадр: вспышка портала, Тимур вылетает из воронки и падает лицом в песок. Пыль, тряска камеры.

**ТИМУР**
```
[muffled] Ай. [pause] Я в порядке. Песок, кстати, вкусный. Нет, вру, совсем невкусный.
```

## СЦЕНА 4. Связь с Зарой (0:45–1:05)
Кадр: голограмма Зары с чашкой чая над браслетом Тимура.

**ЗАРА**
```
[calm] Тимур, слышишь меня? Ты на планете скорпионов. [sips tea] Не паникуй.
```

**ТИМУР**
```
[nervous laugh] Планета ЧЕГО?! Ха-ха. Отличная шутка, профессор. Это же шутка, да?
```

**ЗАРА**
```
[dry] Я никогда не шучу до второй чашки чая.
```

## СЦЕНА 5. Урок 1: не беги (1:05–1:30)
Кадр: из песка вылезают тёмные скорпионы. Потом синий чертёж: скорпион и волны вибрации.

**РАССКАЗЧИК**
```
[calm] Местные скорпионы почти ничего не видят. Зато они чувствуют каждое движение песка. [ironic] Поэтому бегущий подросток для них звучит как звонок к обеду.
```

**ЗАРА**
```
[calm] Замри. Не беги. Дыши медленно.
```

**ТИМУР**
```
[whispers, scared] Замер. Не бегу. Дышу. [squeaks] Он на меня смотрит!
```

## СЦЕНА 6. Урок 2: ультрафиолет (1:30–1:55)
Кадр: Тимур достаёт фонарик, фиолетовый луч, скорпионы светятся бирюзой.

**ЗАРА**
```
[calm] В кармане ультрафиолетовый фонарик. Включи. Под ним скорпионы светятся, и ты увидишь, куда ставить ногу.
```

**ТИМУР**
```
[amazed] Ого… они светятся, как новогодняя гирлянда. [nervous] Очень злая новогодняя гирлянда.
```

**РАССКАЗЧИК**
```
[slightly ironic] Так Тимур выяснил, что красота и опасность прекрасно уживаются вместе. Как кактус в подарочной упаковке.
```

## СЦЕНА 7. Великан (1:55–2:25)
Кадр: песок вздымается, вылезает гигантский скорпион размером с автобус. Тимур крошечный.

**ТИМУР**
```
[screams] Профессор! У нас тут… очень большой вопрос! Размером с автобус!
```

**ЗАРА**
```
[calm] Возьми камень. Брось его подальше в сторону. Он пойдёт на звук.
```

**ТИМУР**
```
[determined] Камень… камень… вот! [grunts] Лови, большой!
```

**РАССКАЗЧИК**
```
[ironic] Великан ушёл на звук. Камень так и не понял, за что его так.
```

## СЦЕНА 8. Кристалл и портал (2:25–2:40)
Кадр: светящийся кристалл на скале. Тимур хватает его, портал открывается, Тимур прыгает.

**ЗАРА**
```
[urgent] Кристалл! Он нужен для портала. Хватай и прыгай. Сейчас!
```

**ТИМУР**
```
[excited] Есть кристалл! До свидания, планета скорпионов! [shouts] Я вам оценку ставлю «два»!
```

## СЦЕНА 9. Тайная комната (2:40–3:00)
Кадр: тёмная комната с красными экранами. Злодей в кресле, вид со спины. НОВА с КРАСНЫМ глазом.

**НОВА**
```
[neutral] Объект вернулся на базу. Кристалл у него. Профессор ничего не подозревает.
```

**РАССКАЗЧИК**
```
[serious] А Тимур пока не знает главного. [pause] Иногда опаснее всего не тот, кто прячется в песке. А тот, кто летает рядом.
```

Финальная карточка: «ПРОДОЛЖЕНИЕ СЛЕДУЕТ…»
